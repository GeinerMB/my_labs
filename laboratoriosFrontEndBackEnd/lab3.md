## Laboratorio 3: Creación front end project usando Vue.js

**Nombre:** Geiner Montoya Barrientos  
**Carné:** C25063

1. Vue.js es un framework de JavaScript para construir interfaces de usuario y aplicaciones web de una sola página (SPA), basado en componentes reutilizables.

2. Un componente en Vue es una unidad independiente y reutilizable de interfaz que combina estructura (template), lógica (script) y estilos (style).

3. La estructura típica de un proyecto en Vue incluye archivos de configuración (por ejemplo, `package.json`), carpeta pública (`public/`) y código fuente en `src/` con archivos como `main.js`, `App.vue` y `components/`.

4. `App.vue` es el componente raíz de la aplicación, define la estructura principal que se renderiza y desde donde se integran otros componentes.

5. `v-if` renderiza o elimina elementos del DOM según una condición booleana; `v-for` permite iterar listas para renderizar elementos repetidos.

6. Un componente global en Vue es aquel registrado a nivel de aplicación y disponible en cualquier componente sin necesidad de importarlo en cada archivo.

7. Un componente local en Vue es aquel registrado dentro de un componente específico y solo puede usarse en ese contexto donde fue declarado.
